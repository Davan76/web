# TOEIC 多益單字 SRS 字卡

單一 `index.html`，離線即可使用的多益單字字卡（9,698 字，含 IPA 音標、字首字根字尾、搭配詞、例句與 SRS 複習）。

## 資料來源與授權
- 單字資料：[kknono668/toeic-vocab-tw](https://huggingface.co/datasets/kknono668/toeic-vocab-tw)
- 字首字根字尾拆解：[MorphoLex-en](https://github.com/hugomailhot/MorphoLex-en)（Sánchez-Gutiérrez, Mailhot, Deacon et al., 2018），CC BY-NC-SA 4.0
- 音標：CMUdict（Carnegie Mellon University），美式發音，由 ARPAbet 轉成 IPA
- 標示「字源推測」的拆解為本專案自行補充，非 MorphoLex 資料，可能有誤

因為含 MorphoLex 資料（CC BY-NC-SA 4.0），本專案僅限非商業使用。
